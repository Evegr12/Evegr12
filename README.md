## Proyectos destacados

### Sistema de gestión telefónica

Aplicación de consola desarrollada en equipo durante un hackathon de Java para administrar contactos telefónicos mediante un menú interactivo.

El sistema permite registrar, consultar, listar y eliminar contactos, además de validar los datos ingresados por el usuario y manejar diferentes situaciones mediante excepciones.

**Tecnologías:** Java, programación orientada a objetos, arreglos, excepciones, validaciones, Git y GitHub.

**Modalidad:** Hackathon colaborativo.

[Ver repositorio](https://github.com/Evegr12/Sistema-de-gestion-telefonica)

---

### Sistema de mantenimiento de cisternas y tinacos

Sistema web desarrollado durante mi servicio social para apoyar la administración, consulta y seguimiento del mantenimiento de cisternas y tinacos.

La aplicación facilita el registro de información, la consulta de servicios y la gestión de datos relacionados con las actividades de mantenimiento.

**Tecnologías:** Laravel, PHP, Blade, JavaScript, CSS y MySQL.

[Ver repositorio](https://github.com/Evegr12/Sistema_de_mantenimiento_de_cisternas_y_tinacos_Segiagua)

### Marcando Huellitas

E-commerce colaborativo de productos y recursos para mascotas. La plataforma integra información sobre productos, adopciones, donaciones, refugios y bienestar animal.

Participé en el desarrollo de funcionalidades e interfaces del proyecto, trabajando mediante ramas y control de versiones con un equipo de desarrollo.

**Tecnologías:** HTML, CSS, JavaScript y Bootstrap.

**Metodología:** Scrum y trabajo colaborativo con GitHub.

---

### Waste Tracker

Aplicación web orientada al registro y seguimiento de residuos orgánicos, desarrollada para fomentar una gestión más responsable y organizada.

El proyecto incluye operaciones CRUD, persistencia de información, interacción con mapas y comunicación mediante sockets.

**Tecnologías:** HTML, CSS, JavaScript, Node.js y MySQL.

[Ver repositorio](https://github.com/Evegr12/Waste_Tracker)
